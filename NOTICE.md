# Notice

This is an unofficial reference. 'ExoMars' and 'Rosalind Franklin' refer to the ESA mission and rover; this repository is not affiliated with ESA, Thales Alenia Space, Airbus, Leonardo or any other party to the mission.

## Data used
- **ESA SPICE Service, ExoMarsRSP Operational SPICE Kernel Dataset**, https://doi.org/10.5270/esa-uvyv4w5 (frames kernel `emrsp_rm_v014.tf`, structure kernel `emrsp_rm_struct_v007.bsp`). The kernels are public; this repository contains only numbers read from them, and a script that downloads them from ESA. Cite the DOI when you use them.
- **Vago et al. 2017**, Astrobiology 17(6-7):471-510, Fig. 4 and text (published under CC BY 4.0). Dimensions and labels read from the figure.
- **Coates et al. 2017**, Astrobiology 17(6-7):511-541 (CC BY 4.0), PanCam dimensions and the calibration target and fiducial markers.
- Other papers, slides and web pages listed in `docs/SOURCES.md` are cited for the facts they state; none of them is reproduced here.

## What this repository does not contain
No images, videos, point clouds, 3D models, datasheets, kernel files or text copied from third parties. Values that were measured from public ESA imagery are our own measurements; the images are not included.
